#  Task CLI Manager

> Sistema de gerenciamento de tarefas via linha de comando (CLI) desenvolvido em Python, com persistência de dados relacional utilizando **SQLite3**.

---

##  Tecnologias Utilizadas
- **Python 3** (Lógica e estrutura do sistema)
- **SQLite3** (Banco de dados relacional embutido)
- **OS Module** (Gerenciamento de diretórios e ambiente)

---

##  Funcionalidades (CRUD)
- **Adicionar Tarefa:** Insere título, categoria e define automaticamente o status padrão como "Pendente".
- **Listar Tarefas:** Exibe um painel formatado em tabela no terminal com ID, Título, Categoria e Status.
- **Concluir Tarefa:** Atualiza de forma dinâmica o status de uma tarefa específica utilizando o ID correspondente no banco de dados.
